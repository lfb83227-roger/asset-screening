7×24 自动轮询部署说明

PRD 要求「全天候自动轮询抓取」。生产环境用系统计划任务定时调用 CLI 即可：

# Linux crontab：每 30 分钟跑一轮全平台采集
*/30 * * * * cd /opt/asset-system && /opt/venv/bin/python run.py crawl >> data/logs/crawl.log 2>&1

# 或使用常驻进程（内置间隔循环）
python run.py schedule --interval 1800

# Windows 任务计划程序：调用
#   python.exe D:\asset-system\run.py crawl
