# 独立服务器部署指南（保姆级）

> 适用：一台干净的 Linux 云服务器（推荐 Ubuntu 24.04 LTS）。
> 全程照抄命令即可，每一步都可以直接复制粘贴。
> 如果你拿到的是 Windows Server，告诉我另出方案。

## 一、连接服务器

在你 Windows 电脑上打开 PowerShell 或 Windows Terminal：

```bash
ssh root@你的服务器公网IP
```

- 密码在云厂商控制台可以重置（重置后记住它）
- 第一次连接输 `yes` 确认指纹
- 登录成功后你就在服务器上了，下面所有命令都在**服务器上**执行

## 四、装依赖 + 初始化（约 2 分钟）

```bash
# 1. 建虚拟环境
python3 -m venv venv

# 2. 装依赖（用清华镜像，国内快很多）
venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 初始化数据库 + 15 条样本数据
venv/bin/python run.py init --with-samples

# 4. 试运行（前台跑，Ctrl+C 退出）
APP_HOST=0.0.0.0 APP_PORT=8000 venv/bin/python run.py serve
```

看到 `服务启动中…… http://0.0.0.0:8000` 就成功了。
**另开一个 SSH 窗口**验证：

```bash
curl http://127.0.0.1:8000/api/health
# 返回 JSON 即正常
```

验证完 Ctrl+C 停掉，进下一步。

## 五、安全加固（必须做，1 分钟）

```bash
# 生成随机密钥并复制输出（第六步 systemd 要用）
venv/bin/python -c "import secrets; print(secrets.token_hex(32))"
```

**修改三个默认口令**：等第七步开放端口、浏览器能访问后，用 admin/admin123 登录 →
「用户管理」页 → 把 admin / operator / viewer 三个账号的密码全改掉。
（仓库是公开的，默认口令人人可见，这步不能跳。）

## 六、systemd 守护进程（开机自启 + 崩溃自动重启）

```bash
# 生成密钥（如果第五步还没生成）
SECRET=$(venv/bin/python -c "import secrets; print(secrets.token_hex(32))")

# 写服务配置
cat > /etc/systemd/system/asset-screening.service <<EOF
[Unit]
Description=AI Asset Screening System
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/asset-screening
Environment=APP_HOST=0.0.0.0
Environment=APP_PORT=8000
Environment=APP_SECRET_KEY=${SECRET}
ExecStart=/opt/asset-screening/venv/bin/python run.py serve
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

# 启动 + 设为开机自启
systemctl daemon-reload
systemctl enable --now asset-screening

# 查看状态
systemctl status asset-screening --no-pager
```

看到 `active (running)` 绿字就成功了。常用运维命令：

```bash
systemctl restart asset-screening    # 重启
systemctl stop asset-screening       # 停止
journalctl -u asset-screening -f     # 实时看日志（Ctrl+C 退出）
journalctl -u asset-screening -n 100 # 看最近100行日志
```

> 注意：`APP_SECRET_KEY` 写进了 service 文件，保护它的读权限：
> `chmod 600 /etc/systemd/system/asset-screening.service`
> 以后改了 service 文件要 `systemctl daemon-reload` 再 restart。

## 七、开放端口（云厂商控制台操作）

**在阿里云/腾讯云网页控制台**（不是命令行）：

1. 找到你的服务器 → 「防火墙」/「安全组」
2. 添加规则放行 **TCP 8000** 端口（来源 0.0.0.0/0）
3. 保存

然后在你 Windows 电脑浏览器访问：

```
http://你的服务器公网IP:8000/login
```

**到这一步部署已完成**，以下第八步是可选优化。

## 八、（可选）Nginx + 域名，去掉端口号 + HTTPS

有了域名的话体验更专业（`http://你的域名` 直接访问，还能上 HTTPS）：

```bash
# 1. 装 Nginx
apt install -y nginx

# 2. 写反代配置（把 80 转发到 8000）
cat > /etc/nginx/sites-available/asset-screening <<'EOF'
server {
    listen 80;
    server_name _;              # 有域名就填 你的域名

    client_max_body_size 20M;   # CSV/XLSX 导入上传

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF
ln -sf /etc/nginx/sites-available/asset-screening /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

# 3. 防火墙放行 80（控制台安全组同样放行 80）
ufw allow 80/tcp 2>/dev/null; echo ok
```

有域名 + HTTPS 的话再装 certbot（免费证书，自动续期）：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

## 九、（可选）数据备份

数据库就一个文件 `data/app.db`，备份极简单。加个每天凌晨 3 点自动备份：

```bash
apt install -y cron
crontab -e   # 选择 nano 编辑器（选 1），末尾加一行：
```

```cron
0 3 * * * systemctl stop asset-screening && cd /opt/asset-screening && cp data/app.db /root/backups/app-$(date +\%Y\%m\%d).db 2>/dev/null || mkdir -p /root/backups && cp data/app.db /root/backups/app-$(date +\%Y\%m\%d).db; systemctl start asset-screening
```

> 更优雅的做法是停服拷贝（上面的写法已包含启停）。备份文件在 `/root/backups/`，
> 建议定期下载一份到你本地电脑。

## 十、验收清单

部署完成后逐项过：

| 检查项 | 命令/操作 | 期望 |
|---|---|---|
| 服务状态 | `systemctl status asset-screening` | active (running) |
| 健康检查 | `curl http://127.0.0.1:8000/api/health` | 返回 JSON |
| 外部访问 | 浏览器 `http://IP:8000/login` | 登录页正常 |
| 登录 | admin + **新密码** | 进入仪表盘 |
| 样本数据 | `/assets` | 15 条标的 |
| 评分详情 | `/assets/2` | 五维得分明细正常 |
| PDF 报告 | `/assets/2/report.pdf` | 中文正常显示 |
| 开机自启 | `reboot` 后再查状态 | 自动拉起 |
| 崩溃自愈 | `kill -9 $(pgrep -f "run.py serve")` 后等 5 秒 | 自动重启 |

## 十一、故障速查

| 症状 | 排查 |
|---|---|
| 外部访问不通 | ① `systemctl status` 是否 running ② 云控制台安全组是否放行 8000 ③ 服务器内 `curl 127.0.0.1:8000/api/health` 是否正常（正常=网络问题，不正常=服务问题） |
| 启动报 sqlite 错误 | `ls -la /opt/asset-screening/data/` 看目录是否存在、属主是否正确 |
| PDF 中文乱码/方框 | `fc-list :lang=zh` 看有无字体；没有就 `apt install fonts-wqy-zenhei` 后 `systemctl restart asset-screening` |
| 登录后立刻登出 | service 文件里 APP_SECRET_KEY 是否在重启后变了 |
| 改了代码怎么生效 | git pull（或重新上传）→ `systemctl restart asset-screening` |
| 502（用了 Nginx） | 后端挂了：`journalctl -u asset-screening -n 50` 看日志 |

## 附录 D：买哪家的服务器（推荐 + 购买步骤）

**推荐：腾讯云「轻量应用服务器」**（阿里云轻量同样可以，哪家新人优惠大选哪家）。
选轻量而非标准 CVM/ECS 的理由：

- 默认防火墙已放行 22/80/443 → 部署完**大概率零控制台操作**就能访问
- 控制台简单：重置密码、绑定密钥都是一键
- 新用户年付价格通常只有标准云服务器的 1/3 左右

### 购买步骤（腾讯云，5 分钟）

1. 打开 https://buy.cloud.tencent.com/lighthouse
   （新用户先去 https://cloud.tencent.com/act/new 看特惠价，通常 2核2G 年付几十到一百出头）
2. **地域**：选离你近的（广州 / 上海 / 南京 / 北京，后台工具无所谓延迟）
3. **镜像类型**：选「**系统镜像**」→ **Ubuntu 24.04 LTS**
   （没有 24.04 就选 22.04，附录 B 有补装 Python 3.12 的命令）
   ⚠️ 千万不要选「应用镜像」（宝塔/WordPress 那些会预装一堆用不上的东西）
4. **套餐**：2核2G4M 起步（本项目绰绰有余），时长选 12 个月最划算
5. 付费 → 完成

### 买完后（控制台 1 分钟）

1. 控制台 → 轻量应用服务器 → 点进你的实例
2. 记下**公网 IP**
3. 右上角「重置密码」→ 设置 root 密码（界面上会显示默认账号名，Ubuntu 一般是 root）
4. 把「公网 IP + 密码」交给 WorkBuddy，剩余部署全部自动完成

> 阿里云轻量流程几乎一样：https://www.aliyun.com/product/simpleapp ，
> 同样选 Ubuntu 24.04 系统镜像、2核2G 套餐。
